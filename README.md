# kids-breakfast

Fun breakfast tools for the family.

## Breakfast Wheel

Open `index.html` in a browser (phone or tablet works great) and tap **SPIN!**

- Options: Pancakes, French Toast, Oatmeal / MUSH, Scrambled Eggs, Bagels, Cereal, and Go out to DK.
- **Go out to DK** can only be picked once a week (Monday–Sunday). It counts once you tap
  "We're having this!", then it's greyed out and skipped until next Monday. This is remembered
  per device/browser; "Reset DK for this week" undoes it.
- Every result comes with a balanced plate: a random fruit, a protein, and tips. Heavier meals
  (pancakes, French toast, bagels, DK) get extra suggestions to offset the sugar and carbs.

To change the menu, edit the `MEALS` and `FRUITS` lists near the bottom of `index.html`.
