# kids-breakfast

Fun breakfast tools for the family.

## Breakfast Wheel

Live at https://uxandyphil.github.io/kids-breakfast/ (or open `index.html` in any browser). Tap **SPIN!**

### Spin tab
- Every result comes with a balanced plate: a random fruit, a protein, and tips. Heavier meals
  get a "balance it out" tag with extra suggestions to offset the sugar and carbs.
- Tap **"We're having this!"** to log the breakfast.
- Breakfasts marked **once a week** (like Go out to DK) are greyed out and skipped once they've been
  logged that week (Monday–Sunday).

### History tab
- Shows what you've had recently (Today, Yesterday, weekday names…) plus a count for the last 7 days.
- Tap ✕ on an entry to remove a mistake — removing this week's DK entry unlocks DK again.

### Menu tab
- Edit any breakfast's name, emoji, color, plate items, and tip, or tick "once a week" / "heavier meal".
- Add, remove, or reorder breakfasts, and edit the fruit list.
- Changes save automatically. "Reset menu to defaults" brings back the original list (history is kept).

> Menu changes and history are saved in the browser on each device, so use the same phone/tablet for spinning.
